# 爆款句式库

## 写法细节（从示例里归纳）

- 数字写到个位：334、2,234、97 万、1096 万。不用"很多""上百"。
- 感叹号用两个"！！"比一个更像真人，但全文最多出现一两次。
- 中文推文可以用口语和语气词（"啊他喵的""直接""根本"），比书面语更像人。
- 每段一两行，段与段之间空一行，手机上一屏能扫完。
- 步骤与清单序号统一用 `1️⃣` `2️⃣` `3️⃣`，不用 "1. 2. 3." 或 "第一步、第二步"；中间排序项只保留 `1️⃣` `2️⃣` `3️⃣` 序号本身，不要再叠加其他 emoji，否则会显得很乱。
- Emoji 的词库和位置规则以 SKILL.md 的「Emoji 与序号硬规则」为准：只放第一行首位和最后一行首位，不放行尾，情绪类 emoji（`🙏` `😎` `🥳` `😳` `🤡` 等）暂不使用。
- 续集和系列帖的结尾金句保持一字不差，形成辨识度。
- 不加句号：句尾直接换行。
