# 8 种爆款帖类型

数据来自 189 条爆款帖拆解。每种类型都标了它擅长拿的数据，选类型前先对照 SKILL.md 的 Step 1。

---

## 1. 一句话 + 作品

擅长：浏览。缺点：收藏率最低，涨流量不涨粉。

文字不用解释，一句话给别人一个点开的理由，剩下交给视频或图片。

模板：

```
这个【作品】花了【成本】，用了【时间】
```

```
【一个画面/一个结果，一句话】
[视频/图片]
```

原帖示例（@iamneubert，1096 万浏览）：

> This ad cost $9 and took 10 minutes to make.

拆解：只有两个数字，9 美元、10 分钟。低成本 + 短时间 + 视频里的高质量结果，形成反差，人会点开看"真的吗"。

---

## 2. 我用 X 做了 Y（爆了马上出续集）

擅长：浏览，续集能放大。

模板：

```
我用【工具】做了【具体作品】，【一个吓人的具体数字】

【一句金句/判断】
```

续集模板：

```
你们喜欢上一条【上一条的作品】……

我用【工具】做了【更大的作品】，【更大的数字】！

【同一句金句】
```

原帖示例（@ashebytes）：

第一条，113 万浏览：

> I used GPT-6 Astra to create a 3D website that pulls apart a Tesla Model X into 334 modeled pieces
>
> we are in a renaissance of learning

第二天续集，805 万浏览，翻了 7 倍：

> since you guys loved the exploding tesla..
>
> I used GPT-6 Astra to create a 3D website that pulls apart the male anatomy into 2,234 modeled pieces!
>
> we are in a renaissance of learning

拆解：
- 数字越具体越好，334、2,234 比"很多零件"有说服力。
- 续集开头直接引用上一条的热度，给老观众一个"接着看"的理由，给新观众一个"上一条很火"的社会证明。
- 结尾金句两条完全一样，形成系列感。

---

## 3. 清单合集

擅长：收藏。189 条里收藏率前 6 名有 5 条是清单。缺点：浏览中位数只有 14 万。

模板：

```
🔥🔥🔥 【一个趋势/现象】，挑了 【N】 个【能直接用的】，建议收藏：

1️⃣ 【名字】（【一个可信度指标，如 star 数】）
【它能帮你做什么，一两句】
【链接】

2️⃣ ……
```

多个链接时，链接跟着各项放在正文里；如果整条只有 1 个合集链接，就从正文删掉，放进评论区自回复，最后一行写 `👇👇👇 链接放评论区`。

"建议收藏"只保留开头这一处，结尾不再写 `📌 建议收藏`。多链接时结尾可以不写，或用问题结尾（如 `你还知道哪些？`）。

原帖示例（@DDJCXX，10 万浏览，收藏率 3%，是平均的 6 倍多）：

> 这个月 GitHub 上冒出来一批让 Claude Code 做视频、做动画的 Skill，挑了 8 个能直接用的，建议收藏：
>
> 1.pixelfx（约 750 star）
> 244 个像素特效，火、爆炸、魔法、天气，全是代码写的。附一个 Skill，让 Claude 像挑剔的像素画师一样做新特效：画、渲染、看、再改。

拆解：
- 原帖序号写的是 `1.`，套用时一律改成 `1️⃣` `2️⃣` `3️⃣`，序号项里不叠加其他 emoji。
- 原帖挑了 8 个，套用时最多 6 项，开头的数字也跟着写 6 以内。
- 开头一句话交代趋势（这个月冒出来一批）+ 筛选（挑了 8 个）+ 门槛低（能直接用的）+ 行动（建议收藏）。
- "建议收藏"放在开头而不是结尾，第一屏就给出动作指令。
- 每项写"能做什么"，并用 star 数做背书。
- 配一张拼图把所有项都展示出来。

## 4. 免费福利

擅长：浏览 + 收藏。

公式：原价多少 → 现在免费 → 截止时间 → 两三步领取。没有价格对比，"免费"两个字就没有分量。

模板：

```
🔥🔥🔥 【情绪词】，【一句话定性】！！
【产品】【时长】免费领，
相当于【原价】的【产品】直接白送，

不用【门槛 A】，不用【门槛 B】，【所有人】都能领，

截止【日期】

领取方法：
1️⃣ ……
2️⃣ ……
3️⃣ ……

👇👇👇 领取入口放评论区
```

福利通常只有 1 个领取链接，按单链接处理：链接放进评论区自回复，最后一行引导评论区。没有链接时最后一行改成 `📌 建议收藏`。

原帖示例（@AYi_AInotes，132 万浏览）：

> 卧槽兄弟们，这个必须卧槽了，
> 老马掀桌子了！！
> Cursor Pro 一整年免费领，
> 相当于一年 240 刀的 Cursor Pro 直接白送啊他喵的，
>
> 不用学生证，不用教育邮箱，全球任何人都能领，
> 属于官方开启的全员零元购模式了😳
>
> 正常 20 刀一个月的顶级 AI 编程工具账单直接清零，
> 截止 10 月 15

拆解：情绪词（卧槽）+ 价格对比（240 刀 → 白送）+ 去门槛（不用学生证、不用教育邮箱）+ 时间紧迫（截止 10 月 15）。四种开头公式叠在前几行。原帖里的 `😳` 属于情绪类 emoji，且放在行尾，套用时不要照抄。

## 5. 一句干货

擅长：浏览 + 收藏（收藏率可接近 2%）。

不用长，一句能马上用的技巧就够了。

模板：

```
一个私藏的实用技巧：
【做 X 时】，【一个具体动作】，你会发现【一个具体结果】！！
```

```
最近用【工具】做了不少【事】，发现一个【避免某问题】并且【让结果更好】的秘诀：

在【具体位置】里加上 "【可直接复制的那句话】"
```

原帖示例：

@yyyole，137 万浏览：

> 一个私藏的实用技巧：
> 用AI写文章时，禁止它使用副词，你会发现写出来的内容，会很有画面感！！

@luinlee，54 万浏览，收藏率接近 2%：

> 最近用 Opus 和 Astra 写了不少 UI，发现一个避免 AI slop 并且让界面更好看的秘诀：
>
> 在 AGENTS.md 里加上 "Avoid unnecessary secondary labels and descriptions. Let the layout do the explaining."

拆解：
- "私藏""秘诀"制造稀缺感。
- 技巧必须是一个动作，最好是能直接复制的一句话。
- "最近用 X 写了不少 Y"是身份背书，说明这是实践出来的。
- 原帖没写结尾。目标是收藏时，可以补一行 `📌 建议收藏`。

## 6. 外网热点搬运

擅长：浏览。

英文区先爆、中文区还没人发，就是机会。用几乎一样的结构发中文版，浏览可能反而更多。必须用自己的话写，加上自己的看法，最好注明出处。

模板：

```
🚨 【新东西】才上线 【N】 小时

我刷了一圈 X，已经有人在拿它干离谱的事了

👇 这 【N】 个最令人眼前一亮
```

出处（原帖作者 @ 和链接）写成一条评论区自回复，跟主帖一起交付，不要省略。串推里的 N 条内容不写。

原帖示例：

英文原帖（@TawohAwa，106 万浏览）：

> 🚨 BREAKING: It's only been 15 hours since GPT 6 Astra launched.
>
> And people are already building some absolutely insane things with it.
>
> Here are 10 wildest projects we've seen so far. 👇

6 个半小时后的中文版（@JacksAISites，169 万浏览）：

> 🚨 GPT-6 Astra 才上线 15 小时。
>
> 我刷了一圈 X，已经有人在拿它干离谱的事了。
>
> 这 10 个最令人眼前一亮👇

拆解：
- 结构三段：时间紧迫 → 已经有人在做 → 我挑了 N 个 + 👇 引导看串推。
- 中文版不是直译，加了"我刷了一圈 X"，把自己放进去。
- 本质是"热点 + 清单"的组合。

## 7. 推荐别人的内容

擅长：浏览。

你不一定要自己写长文，帮大家找到好东西也是价值。推荐语两句就够，关键是用行为代替形容词。

模板：

```
我现在几乎每【周期】都会【重读/重看】一遍

毫不夸张地说，这是我【读过/用过】的关于【主题】的、最有价值的【内容】之一

[引用原帖]
```

原帖示例（@huxlab，323 万浏览；同一篇文章的西班牙文推荐 @vendel_tomas 235 万浏览）：

> 我现在几乎每周都会重读一遍。
>
> 毫不夸张地说，这是我读过的关于如何改变你生活的、最有价值的文章之一。

拆解："每周都会重读"是一个行为证据，比"强烈推荐"有力得多。

## 8. 提问和搞笑

擅长：回复。缺点：评论很多，几乎没人收藏。

提问：只问一个二选一的问题。原帖（@StefanoGPT，18 万浏览）1019 条回复，回复率是平均的 12 倍。

提问模板：

```
【A】还是【B】？
```

```
如果只能留一个，你选【A】还是【B】？
```

搞笑常用三段式：前两个正常，第三个是笑点。

搞笑模板：

```
如果你有【同样的条件】：

【对象 A】：可以【正常的好处】
【对象 B】：可以【正常的好处】
【对象 C】：可以【荒诞的反转】
```

原帖示例（@ai_funss，20 万浏览）：

> 如果你有$20订阅了AI的套餐：
>
> Claude Pro：可以尽情使用Opus 5.5 的 30亿Token
> ChatGPT Plus：可以尽情使用6.1 Sol 的 8.7亿Token
> Kimi Pro：可以尽情看两只鹈鹕骑自行车🤡🤡🤡

拆解：前两行建立"同样的钱买到很多"的预期，第三行用圈内梗打破，句式完全对齐，笑点才落得准。原帖第三行末尾的 `🤡🤡🤡` 属于情绪类 emoji，套用时去掉。
